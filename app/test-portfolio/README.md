# Test Portfolio Layout

Este layout esqueleto está diseñado para pruebas de UI, siguiendo los wireframes proporcionados. Es completamente responsive y utiliza Tailwind CSS.

## Estructura

- `page.tsx`: Renderiza el layout principal.
- `ui/TestPortfolioLayout.tsx`: Contiene la estructura general y placeholders para los componentes internos.
- `layout.tsx`: Wrapper opcional para providers o estilos globales.

## Uso

Reemplaza los componentes `Placeholder` por tus componentes reales según corresponda:

- Sidebar/Listas
- Detalles principales/Documentos/Status
- Tabs de Chat, Documentos, etc.
- Input de mensajes o acciones

El layout adapta la disposición según el tamaño de pantalla (desktop/tablet vs. mobile).
